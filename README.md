# ASTREC Business Assistant Bot

Telegram-бот — единая точка входа для заявок предпринимателей: подбор персонала,
HR-консалтинг и маркетплейс специалистов (юристы, бухгалтеры, налоги, PR,
кадровый учёт, бизнес-аналитика, бизнес-планирование, маркетинг, обучение,
организация форумов/ивентов/стратегических сессий).

**Как работает:** пользователь выбирает тему → отвечает на 4 вопроса (суть,
срочность, бюджет, контакт) → заявка целиком уходит в личный чат администратора
(`ADMIN_CHAT_ID`). Бот НЕ распределяет заявки специалистам автоматически —
это делает администратор вручную.

## Настройка

1. Создайте бота через [@BotFather](https://t.me/BotFather), получите токен.
2. Узнайте свой `chat_id`:
   - запустите бота (после деплоя) командой `/start`,
   - затем отправьте ему `/myid` — он пришлёт ваш `chat_id`.
3. Задайте переменные окружения (см. `.env.example`):
   - `BOT_TOKEN` — токен от BotFather
   - `ADMIN_CHAT_ID` — ваш chat_id (заявки будут приходить сюда)

## Локальный запуск

```bash
pip install -r requirements.txt
export BOT_TOKEN=xxxx
export ADMIN_CHAT_ID=xxxx
python main.py
```

## Деплой на Railway

1. Код уже в этом репозитории: `astrec-kz/astrec-kz-business-assistant-bot.`
2. В Railway: New Project → Deploy from GitHub repo → выбрать этот репозиторий.
3. В настройках сервиса добавить переменные `BOT_TOKEN` и `ADMIN_CHAT_ID`.
4. Railway автоматически подхватит `Procfile` и запустит `worker: python main.py`.

## Как расширять

- **Категории услуг** — список `CATEGORIES` в `main.py`. Каждая строка:
  `(ключ, "Название с эмодзи", track)`, где `track` — `"own"` (услуги Карины)
  или `"market"` (маркетплейс специалистов). Сейчас `track` только хранится
  в данных заявки для будущей аналитики — на логику бота не влияет
  (все заявки одинаково падают в ADMIN_CHAT_ID).
- **Анкета** — сейчас единая для всех категорий (суть / срочность / бюджет / контакт).
  Если понадобятся свои вопросы под категорию — расширить `ConversationHandler`
  дополнительными состояниями с условным переходом по `category_key`.
- **Учёт заявок** — сейчас заявки нигде не сохраняются, кроме пересылки в чат.
  Для истории/отчётности можно добавить запись в Google Sheets (через Zapier
  или `gspread`) или в базу данных (Postgres на Railway).
- **Роутинг специалистам** — на будущее, когда объём вырастет: можно хранить
  контакты специалистов по категориям и добавить кнопку «Переслать специалисту»
  прямо в чате администратора.
